# Porting notes

Traceability back to the original C++ source (`../source`), kept for
validating this rewrite and for anyone porting a module not yet listed
here - not the primary architecture reference (see the top-level
README for that). Ported bottom-up by dependency; each module is an
idiomatic redesign, not a mechanical line-by-line translation, with its
own tests.
